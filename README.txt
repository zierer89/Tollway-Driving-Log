Illinois Tollway Driving Log offline PWA prototype.

To install: host this directory on a consistent HTTPS URL (a free static hosting plan can work), open that link in iPhone Safari, Share > Add to Home Screen. Open using the same icon/origin every time. Files app HTML preview is not a reliable storage environment.

Records and PINs are stored on EACH PHONE, not synchronized. First-run employee setup is per device; supervisor-created accounts on one phone do not distribute to other phones. PINs are weak local access gates, NOT audit-grade access controls.

Monthly data saves in browser localStorage, which can be deleted by the OS/user. Download JSON backups frequently and external PDFs before finalization. Print/Save PDF depends on iOS/browser print UI. The app cannot confirm an email was delivered or externally saved. Do not rely solely on this prototype for regulated record retention.
